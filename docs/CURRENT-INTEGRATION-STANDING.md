The [public explainer](https://phlogiston.app/) is a separate static
page served through the existing host/Caddy mechanism, not community activation.
[Private early-access invitations](EARLY-ACCESS-INVITES.md) are planned for a
future cohort; no public signup is offered and this lane adds no launch gate.

Phlogiston has zero real users, no irreplaceable user repository state and no
current PDS continuity promise. Host-loss reconstruction from retained source,
configuration, appropriately held credentials/enrollment records and small
operational state is the current requirement. Existing restore rehearsals are
useful hardening. Total-site-loss recovery is outside the current envelope;
geographic/off-site recovery-key custody is not a launch gate. User-data/PDS DR
becomes a future requirement if user state is hosted or durability is promised.

Juche is non-normative for Phlogiston's operational posture, user commitments,
production classification and durability requirements; it is an implementation
reference only.
